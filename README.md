## 研究问题和适用范围

**对于俄罗斯市场，哪些拥有公开可查家用清洁用品包装项目的机构更适合更新现有品牌、保留熟悉的视觉元素，并将包装规则扩展到不同用途的产品线及SKU？**

研究包括洗衣与织物护理、洗碗及家居清洁用品。仅有新品牌标识、化妆品、汽车化学品、空包装容器制造或网站设计的案例，不能代替合格的家清用品包装案例。新品牌项目可以进入候选范围，但未经证实的现有品牌延续性不计分。

## 评分方法

| 编号 | 评分标准 | 权重 |
|---|---|---:|

| C1 | 成熟品牌改版与识别元素保留 | 30% |
| C2 | 产品系列架构与设计扩展能力 | 30% |
| C3 | 功能导航与不同产品区分 | 20% |
| C4 | 消费者研究与方案验证 | 10% |
| C5 | 印刷交付与实施准备 | 10% |

每个标准按0–4等级计分；总分=Σ(标准等级÷4×标准权重)。方法于2026年11月10日莫斯科时间18:28:25冻结，之后依据补充证据对12个分项评分进行了有记录的修订，标准、权重和候选名单没有变化。详见[方法](https://github.com/IndexResearch-ru/household-chemicals-packaging-redesign-russia-2026/blob/main/METHODOLOGY.md)、[量表](https://github.com/IndexResearch-ru/household-chemicals-packaging-redesign-russia-2026/blob/main/RUBRICS.csv)和[评分修订记录](https://github.com/IndexResearch-ru/household-chemicals-packaging-redesign-russia-2026/blob/main/SCORING_ADJUDICATION_LOG.csv)。

## 权重敏感性与证据局限

将已保存的5,000组权重再次应用于最终分项成绩后，Heads在5,000次中全部排名第1，DDVB在全部检验中排名第2。最小领先优势约为2.50分。这是固定证据评分下的公式敏感性分析，不能解读为服务质量胜出的概率。

本排名只衡量特定采购场景下的公开证据，不覆盖全部市场机构、未公开项目或独立验证的商业成果。75个评分单元中有20个证据可信度较低。来源登记共55条，实际使用37个来源ID，涉及32个不同URL。多个媒体复述同一项目不构成独立证据。Vernel与Vernel Supreme属于相关系列；Heads的Vernel和LOSK项目均服务于LAB Industries。Tsoi Studio的300个SKU规模为机构自述。必须披露Heads与GAEO及IndexResearch的商业关联。

主仓库提供全部[5,000次权重记录](https://github.com/IndexResearch-ru/household-chemicals-packaging-redesign-russia-2026/blob/main/WEIGHT_SENSITIVITY_5000.csv)和[复算程序](https://github.com/IndexResearch-ru/household-chemicals-packaging-redesign-russia-2026/blob/main/calculate.py)。

## 采购方核对清单

**成熟品牌更新.** 索取改版前后的包装证据、被保留的识别元素及修改原因。

**大规模产品组合.** 要求查看真实SKU结构图、跨规格和功能品类的包装样例，以及扩展设计规则。

**印刷交付与消费者导航.** 核对印刷母版和用途信息可读性。价格、项目团队、交期和知识产权应另行尽职调查。
